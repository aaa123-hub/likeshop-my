# 蓝湖 UI 功能差异审计

更新时间：2026-07-12

## 处理原则

- 蓝湖 UI 只作为显示结构、视觉风格、颜色和间距参考。
- 原 Likeshop 业务功能、登录态、订单、购物车、地址、优惠券、商家入驻、KYC、推广、分享、扫码等逻辑必须保留。
- 设计图与原功能差异较大时，按原项目功能实现，只调整到接近蓝湖视觉。
- 小程序右上角胶囊视觉已隐藏，原 DOM 尺寸和导航占位保留。
- 后端会替换的数据不再用具体商品、店铺、人名、手机号等静态假数据兜底。
- 蓝湖图片必须使用服务器 URL；找不到或未上传的图片先用空图/占位并记录。
